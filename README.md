# Портфолио Telegram-ботов — Mini App

Витрина моих работ, которая открывается прямо внутри Telegram как Mini App (Telegram WebApp):
примеры ботов по нишам (салоны, врачи, фитнес и др.) и калькулятор стоимости — клиент выбирает, что нужно его бизнесу,
и сразу видит цену и может оставить заявку.

**Открыть в браузере:** [maksimgrishkov-sudo.github.io/juggernaut-miniapp](https://maksimgrishkov-sudo.github.io/juggernaut-miniapp/)

Один файл `index.html`: HTML + CSS + JavaScript, Telegram WebApp API, хостинг — GitHub Pages.
Используется как витрина в боте «Джаггернаут» — боте продаж и CRM для команды.
